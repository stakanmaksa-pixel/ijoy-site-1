# Apple Watch — 11 сентября 2026

## Что изменилось

- Ultra 3, Series 11 и SE 3 используют единый масштаб по контуру часов, включая ремешок: 76% высоты области изображения. Пустые поля исходного файла больше не уменьшают Ultra 3.
- 24 оригинальных фотографии Apple поставляются вместе с приложением. 30 точных адресов прежнего импорта автоматически заменяются локальными фотографиями соответствующего корпуса, размера и ремешка. Произвольные фотографии, загруженные вручную, не заменяются.
- Подготовлена Apple Watch Ultra 4: два варианта 49 мм — Black Titanium / Ocean Band (Translucent Black) и Natural Titanium / Ocean Band (Translucent Gray). Новые варианты без цены и подтверждённого наличия: «Уточняйте у менеджера». Дополнительные ремешки и цены этим обновлением не добавляются.
- Samsung Ultra2 сохраняет прямую ссылку из меню на `/product/samsung-galaxy-watch-ultra-2`: страница сразу показывает два варианта. Переход на полную карточку вместо палитры не вводится.

## Команды на сервере

Выполняйте из существующей папки сайта, по одной строке. Если команда завершилась ошибкой, не переходите к следующей.

```bash
git pull --ff-only origin main
docker compose --env-file .env.docker build app migrate
docker compose --env-file .env.docker up -d --no-deps app
docker compose --env-file .env.docker run --rm migrate npx tsx prisma/scripts/sync-apple-watch-ultra4.ts --dry-run
docker compose --env-file .env.docker run --rm migrate npx tsx prisma/scripts/sync-apple-watch-ultra4.ts
```

Первые три команды обновляют внешний вид существующих часов. Последние две проверяют и добавляют Ultra 4 в базу. Сначала публикуются файлы приложения, затем ссылки на новые фотографии в базе.

Скрипт меняет только Ultra 4: создаёт отсутствующие варианты, заполняет отсутствующие фото и описание. Существующие цены, наличие, ID вариантов, пользовательские фото и статус скрытой карточки сохраняются. Повторный запуск не дублирует известные варианты. Старый общий импорт часов запускать не требуется.

До записи сохраняется резервная копия в `/app/backups/apple-watch-ultra4/before-<timestamp>.json`, в постоянном приватном томе `catalog_backups`. Для новой карточки в копии будет `before: null`. Копия предназначена для контролируемого восстановления, автоматического отката скрипт не выполняет.

После обновления проверьте Ultra 3 рядом с Series 11 / SE 3, оба цвета Ultra 4, выбор ремешков Ultra 3 и переход к двум вариантам Samsung Ultra2. Меню может обновляться до одной минуты из-за кеша.

## Проверки и границы

67 автоматических тестов, TypeScript и production-сборка Next.js прошли. Визуальная проверка через computer-use выполнена на локальной витрине с настоящим ProductCard и production-CSS: ширины 1280 и 375 px, все фото загружаются, масштабы одинаковые, горизонтального переполнения нет. Все 24 оригинала отдельно просмотрены на контактном листе. Серверная база в этих проверках не использовалась; применение скрипта на сервере ещё требуется.

При последней внешней проверке сервер `201.34.139.129:3000` не ответил за 15 секунд; это не устанавливает причину недоступности. Сайт не перезапускался и удалённая база не менялась.
