# Розничная зарядная станция и описания наушников

Зарядная станция DualSense: остаётся существующий вариант «1 шт» (в исходном прайсе 3000 ₽). Варианты «от 10/20/100 шт» переносятся в скрытый архив без удаления ID и истории заказов. Цена и наличие розничного варианта сохраняются. В описании уточнено: продаётся одна станция, контроллеры отдельно. В исходном игровом каталоге оптовые варианты также убраны, чтобы повторный импорт их не возвращал.

Заполнены описания, особенности, характеристики и совместимость девяти моделей: AirPods Pro 3, AirPods Pro 2 Type-C, AirPods 4, AirPods 4 ANC, AirPods Max 2 (2026), EarPods USB-C, Sony PULSE Elite, Sony PULSE 3D и Marshall Major V. Источники производителей указаны для каждой модели в `prisma/data/headphone-content.ts`.

## На сервере

Из папки сайта, по одной команде; при ошибке не переходить дальше:

```bash
git pull --ff-only origin main
docker compose --env-file .env.docker build app migrate
docker compose --env-file .env.docker up -d --no-deps app
docker compose --env-file .env.docker run --rm migrate npx tsx prisma/scripts/sync-retail-headphones.ts --dry-run
docker compose --env-file .env.docker run --rm migrate npx tsx prisma/scripts/sync-retail-headphones.ts
```

Одной пересборки недостаточно: описания и варианты хранятся в базе. Последняя команда обязательна для применения. Общий seed или импорт всего игрового каталога запускать не нужно.

Перед записью создаётся копия прежних данных `/app/backups/retail-headphones/before-<timestamp>.json` в постоянном приватном томе `catalog_backups`. Скрипт повторяемый; скрытые модели не публикует, отсутствующие модели не создаёт. Фото, цены, остатки и варианты наушников не меняет. Изменяет только их текстовые поля, сохраняя дополнительные ключи характеристик.

`SKIP` означает отсутствующую или скрытую целевую модель; `REVIEW` — другую модель наушников без подготовленных данных, которую скрипт оставил без изменений. Неизвестные конфигурации зарядной станции останавливают транзакцию, а не удаляются автоматически.

После применения проверьте станцию в каталоге и товаре: один вариант без оптовых порогов. У наушников проверьте описание модели и характеристики в полной карточке. Архив можно восстановить контролируемым переносом вариантов обратно; автоматический откат не предусмотрен. Производственная база локальными тестами не изменялась.
