# Автоматический сбор прайсов из Telegram

Сервис подключается как отдельный пользовательский Telegram-клиент на официальном TDLib — от аккаунта владельца. Он читает только перечисленные источники и создаёт на сайте одну объединённую партию в «Админка → Импорт прайса». Для `@CartelPricesBot` на каждом временном слоте он ищет кнопку с точной подписью «Полный прайс лист» и активирует её; для обычной reply-клавиатуры это отправляет боту такой текст. Другие сообщения ботам/каналам не отправляются. Действие запоминается на слот и не повторяется во время ожидания дополнительных частей прайса. Цены не меняются, пока администратор не применит совпавшие строки. Сервис не очищает цены товаров, которых нет в очередном сообщении.

Поддерживаются текст сообщения и подписи к сообщениям (включая пересланные посты). Картинки без текстовой подписи, PDF и таблицы пока не распознаются — их OCR/разбор нужно добавлять отдельно после проверки реальных форматов.

## Что понадобится

- `api_id` и `api_hash` приложения Telegram, созданного владельцем аккаунта на [my.telegram.org](https://my.telegram.org).
- Ключ шифрования локальной базы TDLib: создайте его сами командой `openssl rand -base64 32` и внесите в серверный `.env.docker`.
- Ссылки/имена каналов. Публичные источники можно задать как `@username`; для приватного канала без username используйте числовой ID из команды `list`.
- Перед первым запуском вручную откройте диалог `@CartelPricesBot` в Telegram и запустите его, если Telegram предлагает кнопку Start. Сборщик не отправляет `/start`; он нажимает только кнопку «Полный прайс лист».
- Уже настроенный сайт и `BOT_API_TOKEN`, совпадающий с секретом, который проверяет `/api/bot/price-import`.

Не отправляйте коды Telegram, пароль двухэтапной проверки, `api_hash`, ключ шифрования или файлы базы в чат/GitHub. Вход выполняется интерактивно на сервере; зашифрованная база и ключ хранятся в `.env.docker` и Docker volume `telegram_session`. Сам ключ нужно сохранить в менеджере паролей: без него базу не открыть. Сессию можно отозвать в Telegram: «Настройки → Устройства». Учитывайте, что хотя сам сборщик только читает, его Telegram-сессия обладает обычными правами вашего аккаунта.

## Настройка на сервере

1. Добавьте в локальный `.env.docker` параметры (не коммитьте этот файл):

   ```dotenv
   TELEGRAM_API_ID=ваш_api_id
   TELEGRAM_API_HASH=ваш_api_hash
   TELEGRAM_DB_ENCRYPTION_KEY=вставьте_вывод_openssl_rand
   TELEGRAM_SOURCE_CHANNELS=@stock_msk,@xiaomiopt,@DremeAisha,@MiSmartShopA1016,@CartelPricesBot
   TELEGRAM_SCHEDULE=11:00,14:00,17:30
   TELEGRAM_TIMEZONE=Europe/Moscow
   TELEGRAM_POLL_INTERVAL_SECONDS=30
   TELEGRAM_INITIAL_LOOKBACK_HOURS=24
   TELEGRAM_QUIET_MINUTES=5
   ```

   Создайте ключ командой `openssl rand -base64 32`. В список источников внесены присланные ссылки: `stock_msk`, `xiaomiopt`, `DremeAisha`, `MiSmartShopA1016` и `CartelPricesBot`. Время в примере — предварительное, московское; его можно поменять.
   После редактирования ограничьте доступ к файлу: `chmod 600 .env.docker`.

2. В каталоге проекта соберите образ и авторизуйте личный аккаунт. Команда интерактивная: Telegram пришлёт код подтверждения; если включён 2FA, пароль вводится только в терминале сервера.

   ```sh
   docker compose --env-file .env.docker --profile automated-prices build telegram-price-collector
   docker compose --env-file .env.docker --profile automated-prices run --rm -it telegram-price-collector python collector.py login
   ```

3. Посмотрите доступные аккаунту группы/каналы и их ID:

   ```sh
   docker compose --env-file .env.docker --profile automated-prices run --rm -it telegram-price-collector python collector.py list
   ```

   Для приватных источников без публичного `@username` используйте выведенный числовой `id`. Внесите ID или публичные имена в `TELEGRAM_SOURCE_CHANNELS`, например `@supplier_one,-1001234567890`.

4. Заполните также `BOT_API_TOKEN` (тот же секрет, что уже используется сайтом), проверьте список и расписание, затем запустите приложение и сборщик:

   ```sh
   docker compose --env-file .env.docker --profile automated-prices up -d --build
   docker compose --env-file .env.docker --profile automated-prices logs -f telegram-price-collector
   ```

Сборщик проверяет каналы в заданные часы и ждёт 5 минут тишины после последнего ценового сообщения, чтобы успели прийти все части прайса. Для Cartel он сначала запрашивает полный прайс кнопкой; если точная кнопка ещё не найдена, слот остаётся на повторной проверке и партия не отправляется. Если сервис был выключен в момент проверки, новые посты подхватятся на следующем расписании. При первом запуске берутся текстовые сообщения за последние 24 часа; далее — сообщения с момента последней успешной проверки. История ограничена 2000 сообщениями на источник за проход; если лимит превышен или один источник недоступен, партия не отправляется частично.

После первой тестовой партии проверьте журнал источников, количества совпадений и итоговые цены в админке. Применение всех «MATCHED» строк одной кнопкой уже поддерживается. Полностью автоматическое применение цен сейчас намеренно выключено: сначала надо убедиться на настоящих каналах, что их SIM-обозначения и исключения правильно интерпретируются.

Если строку пришлось сопоставить вручную, после подтверждения выбор запоминается для будущих прайсов по модели, памяти, цвету и SIM. Страна поставщика не входит в ключ. Если подтверждённые ранее строки конфликтуют и указывают на разные карточки, система не выбирает одну из них автоматически.

## Управление

```sh
docker compose --env-file .env.docker --profile automated-prices ps
docker compose --env-file .env.docker --profile automated-prices logs --tail=200 telegram-price-collector
docker compose --env-file .env.docker --profile automated-prices stop telegram-price-collector
```

Не удаляйте volume `telegram_session` и не теряйте `TELEGRAM_DB_ENCRYPTION_KEY`, пока хотите сохранять авторизацию. Для выхода отзовите клиент в Telegram → «Настройки → Устройства», затем остановите сборщик.
