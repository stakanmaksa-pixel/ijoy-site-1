# Единые карточки и фотографии — 8 сентября 2026

Карточки моделей и вариантов используют один вид: избранное справа над фото,
цена по центру, кнопка корзины внизу. Сравнение остаётся на странице товара
и в отдельном разделе, но не накладывается на фотографии в каталоге.

Для исходных фотографий Samsung, клавиатур, игровых устройств и фитнес-браслетов
измерены поля вокруг устройства. `ProductPhoto` вписывает предмет целиком,
сохраняя пропорции. Исходные изображения не редактируются. Неизвестные
пользовательские загрузки отображаются через `object-fit: contain`.

## Обновление сервера

Из папки проекта, где находятся `docker-compose.yml` и `.env.docker`:

```sh
git pull --ff-only origin main
docker compose --env-file .env.docker build app migrate
docker compose --env-file .env.docker run --rm migrate npx tsx prisma/scripts/sync-catalog-photos.ts
docker compose --env-file .env.docker up -d --no-deps app
```

Запускайте по очереди; если команда завершилась ошибкой, не переходите к следующей.
Скрипт меняет только ссылки на известные импортированные фото и копирует исходники
Samsung в постоянное хранилище. Цены, остатки, категории и варианты не меняются.
Перед изменением ссылок сохраняется JSON-копия в
`public/uploads/photo-sync-backups/` внутри общего тома uploads.
Повторный запуск допустим. Не требуется полный импорт каталога или удаление томов.

Предварительная проверка без записи:

```sh
docker compose --env-file .env.docker run --rm migrate npx tsx prisma/scripts/sync-catalog-photos.ts --dry-run
```

## Проверка разработчиком

`prisma/tests/catalog-card-layout.test.tsx` проверяет общую разметку, сохранение
идентичности вариантов, отсутствие корзины у недоступного товара, существование
локальных фото и границы их отображения. После добавления новых исходников
метаданные можно пересчитать из корня проекта:

```sh
node prisma/scripts/catalog-photo-bounds.mjs --write
```

Это только измерение исходных пикселей; файлы фотографий не изменяются.
