# iJoy — полная пересборка репозитория (24.08, раунд 3)

Как вы просили — весь проект целиком, а не отдельные файлы. Я собрал и
**проверил полной сборкой** (`npm run build`) — компилируется без единой
ошибки. Внутри: всё содержимое вашего репозитория (я скачал ваш последний
`Code → Download ZIP` как основу), плюс убран весь мусор от прошлых
попыток, плюс все накопленные правки (сердечко, цвета, iPhone).

## Что изменилось в этом раунде

1. **Сердечко избранного** — крупнее, аккуратнее, без бага «выделяются
   все» (было на карточках модификаций — убрано оттуда совсем).
2. **Название цвета видно текстом** рядом с «Цвет».
3. **iPhone 17e** — один розовый цвет вместо двух.
4. **Все модификации iPhone теперь видны полностью**: если у модели 5
   цветов, все 5 показываются в каждом объёме памяти и при каждом типе
   SIM — даже если именно такого сочетания нет в прайсе. Для
   отсутствующих в прайсе сочетаний вместо цены пишется **«Уточняйте у
   менеджера»** — я не стал придумывать цены, которых нет в вашем
   прайсе. Кнопка вместо «Оформить заказ» становится «Уточнить цену» и
   отправляет вам заявку с указанием, что именно спросили (модель,
   память, цвет, тип SIM), без конкретной цены.
   Это касается только iPhone — на другие категории (Samsung, часы,
   планшеты и т.д.) не распространялось, вы просили только про айфоны.
5. Убраны все файлы-мусор от прошлых попыток (5 файлов из корня
   репозитория + папка `ijoy-favorites-fix`, которая появилась в
   прошлый раз по ошибке).

**Технически:** цена модификации в базе данных теперь может быть пустой
(раньше была обязательной) — добавлена миграция, она применится
автоматически при следующей пересборке на сервере, вручную ничего
накатывать не нужно.

## Шаг 1. Полностью заменить репозиторий на GitHub

Так как это ПОЛНАЯ пересборка — самый надёжный способ:

1. Разархивируйте присланный архив у себя на компьютере — внутри будут
   папки `src`, `prisma`, `public` и файлы вроде `package.json`,
   `Dockerfile` и т.д. (без обёртки в ещё одну папку).
2. Зайдите в репозиторий на github.com → **Add file → Upload files**.
3. Выделите у себя на компьютере ВСЕ эти файлы и папки разом (Ctrl+A в
   папке) и перетащите все вместе в область загрузки одним движением.
   GitHub покажет длинный список путей вида `src/lib/catalog.ts`,
   `prisma/schema.prisma` и т.д. — если видите такие пути с папками
   впереди, значит структура сохранилась правильно.
4. Внизу — **Commit changes**. Эта загрузка обновит все существующие
   файлы новым содержимым (не тронет то, чего нет в архиве).

5. **Отдельно удалите** старые файлы-мусор, которых в архиве уже нет, но
   которые ещё остались в репозитории (сама загрузка их не уберёт):
   - `ProductOrder.tsx` (в корне)
   - `VariantCard.tsx` (в корне)
   - `colorSwatch.ts` (в корне)
   - `page.tsx` (в корне)
   - `route.ts` (в корне)
   - папка `ijoy-favorites-fix` целиком (откройте, удалите файлы внутри
     по одному — папка исчезнет сама)

   Открываете каждый файл на github.com → значок корзины (Delete file)
   → Commit changes.

## Шаг 2. Деплой на сервере

В этот раз есть изменение схемы базы данных (цена стала необязательной)
— оно применится автоматически на шаге `up -d --build`, отдельно ничего
делать не нужно. Нужен и повторный сид (обновились цвета и модификации
iPhone):

```
cd /opt/ijoy
```
```
git pull
```
```
docker compose --env-file .env.docker up -d --build
```
```
docker compose --env-file .env.docker run --rm migrate npx tsx prisma/seed.ts
```

## Шаг 3. Проверить

- Сердечко крупнее, бага «выделяются все» больше нет.
- Рядом с «Цвет» видно название цвета.
- У iPhone 17e — один розовый.
- Откройте любой iPhone с несколькими цветами — теперь при переключении
  памяти/типа SIM все цвета остаются кликабельными; если для конкретного
  сочетания цены нет — вместо неё написано «Уточняйте у менеджера», а
  кнопка предлагает «Уточнить цену».
