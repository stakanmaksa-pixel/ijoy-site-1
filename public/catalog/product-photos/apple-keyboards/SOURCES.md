# Apple Magic Keyboard — источники

Все фотографии в этой папке — официальные изображения Apple Store, сохранённые
локально для быстрой и стабильной витрины.

- Magic Keyboard для iPad Pro 11″ M5: Apple Store, артикулы `MWR03` / `MWR23`.
- Magic Keyboard для iPad Pro 13″ M5: Apple Store, артикулы `MWR43` / `MWR53`.
- Magic Keyboard для iPad Air 11″ M4: Apple Store, артикулы `MDFV4` / `MGYX4`.
- Magic Keyboard для iPad Air 13″ M4: Apple Store, артикулы `MDFW4` / `MGYY4`.
- Magic Keyboard Folio для iPad A16: Apple Store, артикул `MQDP3`.

Совместимость сверена с Apple Support:

- https://support.apple.com/en-euro/guide/ipad/ipad4b92bd12/ipados
- https://support.apple.com/en-euro/122272
- https://support.apple.com/en-euro/122273
- https://support.apple.com/en-ie/111845
